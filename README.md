# portfolio

Plain HTML/CSS/JS — no build step. Open `index.html`, or serve the folder:

```sh
python3 -m http.server 8000   # then visit http://localhost:8000
```

- `index.html` — markup
- `css/styles.css` — layout, tokens (colours, fonts, spacing) at the top
- `js/main.js` — the four hats copy (`HATS` at the top) and sticky-note dragging
- `assets/lego-me.png` — placeholder crop of the lego photo; swap in the original image (same file name)
