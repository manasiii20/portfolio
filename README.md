# portfolio

Plain HTML/CSS/JS — no build step. Open `index.html`, or serve the folder:

```sh
python3 -m http.server 8000   # then visit http://localhost:8000
```

- `index.html` — markup
- `css/styles.css` — layout, tokens (colours, fonts, spacing) at the top
- `js/main.js` — the four hats copy (`HATS` at the top), sticky-note dragging, custom cursor
- `assets/` — images from the live Framer site (lego photo, flower, arrow, cursors)

Copy, sizes, colours and motion are matched to manasivinze.com at a 1518px-wide window.
